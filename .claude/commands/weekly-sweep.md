# Weekly warm-lead sweep

Read README.md, docs/OPERATIONS.md and targets.txt. For each nonblank, noncomment target run the documented pipeline with the user's ICP and a distinct target/date slug. A profile URL is harvested with `--profile` (10 posts by default); a post link (`linkedin.com/posts/...`, `/feed/update/...` or `lnkd.in/...`) is harvested with `--post` and only that post is scraped. Cap Prospeo at 100 qualified lookups per target unless the user has specified other limits.

Scoring: if `OPENAI_API_KEY` is empty, harvest first (`src/harvest.py`), then `src/icp.py`, then `src/rank.py --dump`, judge every engager with the rubric in `src/rank.py` SYSTEM, write `output/<slug>/scores.json`, and continue with `run.py --slug <slug> --skip-harvest --scores output/<slug>/scores.json ...`. With the key set, one `run.py` call does it all.

CSV is always produced. `run.py` resolves qualified opaque `/in/ACoAA...` engagers to public URLs automatically (`resolved.csv`, $0.004 per profile; include that in the spend you state); retry just that stage with `uv run src/resolve.py --input output/<slug>/ranked_engagers.csv --output output/<slug>/resolved.csv`. Add --activity only when the user has set TYPESAFE_API_KEY and wants the LinkedIn activity check (run the dry run and state the estimate first). Add --supabase only when the user has configured the database and requested it. If a Smartlead campaign or HeyReach list is supplied, generate a preview. Execute the import only when the user has authorized that campaign import; an active campaign may send emails.

Every run ends with a summary (counts and top rows by name). Paste each target's summary into your reply; the user does not open CSVs. Report per-target errors and artifact paths. Reuse completed Prospeo checkpoints when recovering an enrichment stage. Do not rerun paid harvests merely to retry a destination export. Do not mark harvested leads as contacted. Smartlead duplicate/block/unsubscribe checks must remain enabled. This command does not install a recurring scheduler.
