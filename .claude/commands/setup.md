# First-time setup (no paid calls)

Get this repo ready to run without spending any API credits.

1. Check `uv --version` (uv and Python 3.11+ are required). Run `uv sync` to install dependencies into `.venv`.
2. Scoring choice. Ask the user: should engagers be scored by Claude in this session (default, no key, you do the judging with the rubric in `src/rank.py`), or automatically by OpenAI gpt-4.1-mini (needs `OPENAI_API_KEY`, a few cents per run)? Only mention `OPENAI_API_KEY` below if they choose OpenAI.
3. If `.env` is missing, `cp .env.example .env`. Report only the NAMES of empty keys, for example with `grep -E '^[A-Z_]+=$' .env | cut -d= -f1`. Never read, print or echo values, and never ask the user to paste a key into chat. Explain what each key unlocks: `APIFY_TOKEN` is the minimum for harvesting; `OPENAI_API_KEY` only for the OpenAI scoring choice; `FIRECRAWL_API_KEY` for `--domain` ICP derivation; `PROSPEO_API_KEY` for `--find-emails`; `TYPESAFE_API_KEY` for `--activity`; `SMARTLEAD_API_KEY` only for an actual campaign import; `SUPABASE_*` only for the optional database. Ask the user to fill `.env` in their editor and tell you when done.
4. ICP: if `icp.yaml` exists, summarize it and ask whether to keep it. Otherwise `setup_icp.py` is interactive and cannot be driven from here, so offer two options: the user runs `uv run setup_icp.py` in their own terminal, or you ask the eight intake questions in chat (what they sell; job titles; industries to target; industries to exclude; company size; geographies; buying triggers; hard disqualifiers) and write `icp.yaml` yourself with the keys `titles, industries, industries_out, company_size, geos, triggers, disqualifiers, summary` in that order, matching the style of `icp.example.yaml`. Show the file before writing it. Never invent an ICP from unrelated projects.
5. If `targets.txt` is missing, copy `targets.example.txt` to `targets.txt` and ask for competitor or influencer profile URLs, or specific post links, to add.
6. Mention that `activity.toml` (activity-intel fetch caps, threshold, question wording) exists and is user-owned; do not edit it.
7. Run `uv run python -m unittest discover -s tests -v` and report the result as it is. Finish by pointing the user at `/first-run` for a cheap live test.
