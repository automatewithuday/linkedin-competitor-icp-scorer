# Cheap first run (Apify + scoring only)

Run one small, paid harvest to confirm keys, scoring and the ICP before any real sweep.

1. Preconditions: `.env` has a non-empty `APIFY_TOKEN` (check names only, never values), `icp.yaml` exists, and you have a target. Ask for a profile URL or a post link, or use the first non-comment line of `targets.txt`. If something is missing, point at `/setup` and stop.
2. Decide the harvest mode from the link. A post link (`linkedin.com/posts/...`, `linkedin.com/feed/update/...`, or `lnkd.in/...`) means `--post`: only that one post is scraped, never the author's recent posts. A profile link (`linkedin.com/in/...`) means `--profile` with `--max-posts 3`.
3. State the spend before running and wait for an explicit yes. Profile mode: 3 posts, 20 reactions and 10 comments per post, a few cents of Apify. Post mode: up to 100 reactions and 50 comments, about $0.30 at most.
4. Harvest, nothing else yet:
   - profile: `uv run src/harvest.py --profile <url> --slug scraping-test-01 --max-posts 3 --max-reactions 20 --max-comments 10 --posted-limit month`
   - post: `uv run src/harvest.py --post <url> --slug scraping-test-01 --max-reactions 100 --max-comments 50`
5. Score. If `OPENAI_API_KEY` is empty (the default), you do it: `uv run src/icp.py --slug scraping-test-01 --icp icp.yaml`, then `uv run src/rank.py --dump --slug scraping-test-01`, judge every numbered engager with the rubric in `src/rank.py` SYSTEM (be stingy; the user's own profile and the source author score 1), and write `output/scraping-test-01/scores.json` as `{"results": [{"i", "icp_fit", "intent", "clean_title", "company_guess"}]}` with one object per engager. Then `uv run run.py --slug scraping-test-01 --skip-harvest --icp icp.yaml --scores output/scraping-test-01/scores.json`. If `OPENAI_API_KEY` is set, run the same `run.py` command without `--scores` instead. Do not add `--find-emails`, `--supabase`, `--campaign-id` or `--activity` on this run.
6. The run ends with a summary (counts, fit distribution, top rows by name). Paste it into your reply; the user does not open CSVs. Add the row count, how many qualified rows have public profile URLs, the `Resolve` line (run.py resolves qualified opaque `/in/ACoAA...` ids automatically at $0.004 each; `error` rows mean the run failed, e.g. the free-plan 10-items-per-run limit), and spot-check a few titles against the ICP.
7. If scoring looks off, propose edits to `icp.yaml` or to specific scores and apply them only after the user agrees. Rescoring is free: edit `scores.json`, rerun `run.py --skip-harvest ...`. Never re-harvest just to rescore.
8. Resolve already ran inside `run.py` and wrote `output/scraping-test-01/resolved.csv`. To retry only that stage: `uv run src/resolve.py --input output/scraping-test-01/ranked_engagers.csv --output output/scraping-test-01/resolved.csv --dry-run`, state the estimate, then rerun without `--dry-run`. Optional activity check, only if `TYPESAFE_API_KEY` is set: run `uv run src/activity.py --input output/scraping-test-01/resolved.csv --output output/scraping-test-01/activity.csv --dry-run`, report the eligible count, the estimate and the hard cap, and wait for a yes. Then rerun without `--dry-run` and with `--limit 10`, and show `uv run src/summary.py --input output/scraping-test-01/activity.csv`.
9. Report every artifact path. Do not mark anyone as contacted; nothing has been sent.
